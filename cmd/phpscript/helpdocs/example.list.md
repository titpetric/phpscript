| Example | What it does |
|---|---|
| `phpscript list .` | A markdown inventory of the routes, files and classes of one tree. |
| `phpscript list --bindings` | The functions, classes and constants the runtime registers, instead of scanning a tree. |
| `phpscript list --classes 'HTTP\Client'` | One registered class as a PHP class definition: its docblock, its properties and its method declarations. |
